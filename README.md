# Macrix

Keyboard and mouse macros for Windows, no code required.

- **Website:** https://macrixsuporte.github.io/Macrix/
- **Download:** the latest installer is on the [Releases page](https://github.com/macrixsuporte/Macrix/releases).

Every release includes a `SHA256SUMS.txt` file so you can check that your download is genuine
(`Get-FileHash .\Macrix-Setup-*.exe` in PowerShell). Macrix's built-in updater refuses any file
that doesn't match.

This repository only hosts the Macrix website and the official installers.
The source code is not public.
